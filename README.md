# PDF Мастер 0.3.0

PDF Master is an offline Windows 11 x64 PDF workbench maintained by **ЯСтандарт**. Russian and English OCR, line editing, image signatures/stamps, AcroForms and page tools. Licensed under AGPL-3.0-only; dependencies and corresponding sources are documented in THIRD_PARTY.md.

Source: https://github.com/kxl08362-afk/pdf-master · [Windows builds](https://github.com/kxl08362-afk/pdf-master/actions) · [Releases](https://github.com/kxl08362-afk/pdf-master/releases)

**Code signing policy:** [CODE_SIGNING.md](CODE_SIGNING.md). Current builds are unsigned. SignPath Foundation sponsorship is being prepared; acceptance and signing are not yet granted. [Privacy](PRIVACY.md) · [Contributing](CONTRIBUTING.md) · [Security](SECURITY.md) · [Build checks](BUILD_VERIFICATION.md).

Настольная программа для Windows 11 x64: просмотр и правка PDF, русский/английский OCR, свои подписи и печати, формы, страницы и преобразования. Документы обрабатываются локально. Python, отдельный OCR и интернет для работы не требуются.

## Установка и обновление

Запустите PDFMaster-Setup-0.3.0.exe. Установка выполняется для текущего пользователя без администратора. Новый установщик обновляет предыдущие версии с тем же идентификатором приложения. Библиотека штампов находится отдельно от файлов программы.

Установщик без цифровой подписи издателя; Windows может предупредить о неизвестном издателе. Программа не меняет настройки защиты Windows. Штатное удаление доступно в параметрах Windows → Приложения.

## Быстрый сценарий

1. Откройте PDF кнопкой или перетащите в окно.
2. Для скана нажмите «Распознать текст». После OCR включите «Править текст», нажмите на строку, исправьте её справа и примените изменение.
3. В инструменте «Подпись / печать» загрузите свой PNG/JPEG, задайте ширину и нажмите в нужном месте страницы.
4. Сохраните копию PDF и повторно откройте для проверки. Ctrl+Z отменяет, Ctrl+Y повторяет действие.

## Новое меню и быстрые команды

Светлая панель содержит открытие, отмену/повтор, режимы просмотра, правки текста и подписи, отдельное распознавание и заметную кнопку сохранения копии. Справа показываются настройки выбранного инструмента. Контекстное меню страниц открывается правой кнопкой мыши.

Все функции собраны в меню «Файл», «Правка», «Вид», «Страницы», «Инструменты» и «Помощь». Ctrl+K открывает поиск команд. Введите название или привычное слово: «скан», «OCR», «подписать», «печать», «обрезать», «сжать». Стрелки выбирают команду, Enter выполняет, Esc закрывает поиск. Недоступная команда показывает причину и не запускается.

Основные сочетания: Ctrl+O — открыть, Ctrl+S — сохранить, Ctrl+Shift+S — сохранить копию, Ctrl+E — править текст, Ctrl+F — поиск в документе, Ctrl+0 — по ширине, Escape — просмотр. Из поиска команд Escape возвращает в прежний режим.

## OCR и подготовка скана

Доступны текущая страница/весь документ, русский/английский языки и 200/300/400/600 DPI. 300 DPI подходят обычному документу; 400–600 требуют больше времени и памяти.

По умолчанию страницы с любым готовым текстовым слоем пропускаются. Это сохраняет текст, формы и аннотации смешанного документа. Лист с текстом и картинкой также пропускается; для повторного OCR явно включите принудительный режим.

Опциональное выравнивание исправляет небольшой наклон примерно до 5 градусов. Оно может не помочь фотографии, схеме или сильно перекошенному листу. Контраст регулируется отдельно; полного удаления фона и шумов программа не обещает.

Обработанные OCR-страницы становятся изображениями с поисковым слоем. Их формы и аннотации сводятся в изображение. Сохраняйте исходник. Отмена выполняется между страницами; результат применяется только после успешной обработки.

## Подпись, печать и библиотека

Предпочтителен PNG с прозрачным фоном. Для белого фона есть отдельное удаление. Задайте ширину в миллиметрах, угол и непрозрачность. Положительный угол поворачивает по часовой стрелке. Предварительное изображение помогает выбрать положение; ошибку отмените через Ctrl+Z.

Чтобы использовать изображение снова, явно добавьте его в библиотеку с названием. Позже можно выбрать и удалить локальную копию. Оригинал изображения не меняется и не удаляется. Библиотека: %LOCALAPPDATA%\PDFMaster\stamps. Переносите её на другой компьютер только по своему решению.

Подпись и печать вставляются как изображения. Криптографическая ЭП с сертификатом, КриптоПро и подтверждением подписанта в этой версии не реализована.

## Формы

«Инструменты → Заполнить форму…» показывает существующие AcroForm-поля. Поддерживаются текст, кириллица и флажки; после сохранения поля остаются интерактивными. Списки, переключатели, поля цифровой подписи и XFA обозначаются неподдерживаемыми. Автоматического создания полей из скана нет. Права PDF учитываются, включая отдельно разрешённое заполнение при запрете изменения страниц.

## Страницы и удаление области

Выбирайте страницы через Ctrl/Shift. В меню «Страницы» доступны пакетные поворот, дублирование и удаление; перетаскивание меняет порядок. Пакетная операция отменяется одним Ctrl+Z. Объединение и извлечение страниц также доступны.

«Страницы → Обрезать поля…» изменяет видимую область с учётом поворота. Скрытое содержимое может оставаться внутри PDF. Обрезка не предназначена для удаления чувствительных данных.

«Инструменты → Удалить содержимое области»: протяните прямоугольник и подтвердите. Инструмент удаляет текст, затронутые пиксели и интерактивные объекты выделенной области. Сохраняйте отдельную копию. Очистка всех метаданных, вложений, других страниц, резервных и ранее созданных файлов не обещается. Перед отправкой проверьте области и извлечение текста.

## Преобразования и размер файла

- «Файл → PDF из изображений…»: выберите JPG/PNG/TIFF, проверьте порядок, выберите исходный размер или A4. Поддерживаемые JPEG включаются без повторного кодирования; EXIF учитывается. Многостраничный TIFF создаёт несколько страниц.
- «Файл → Страницы в PNG / JPEG…»: выберите страницы, формат, DPI и папку. Одноимённые файлы без явного решения не заменяются; при отмене новые частичные результаты убираются.
- «Инструменты → Оптимизировать PDF…»: оптимизация структуры без уменьшения разрешения и качества картинок. Показывает реальные размеры и сохраняет копию. Уже оптимизированный файл может не уменьшиться.

## Границы первой серии версий

Редактируются выбранные строки. Автоматической перевёрстки всего документа нет. Если текст не помещается, сократите его или уменьшите шрифт. На скане область текста очищается и заполняется новым; на цветном фоне это может быть заметно. Исходный редкий шрифт не восстанавливается автоматически.

OCR предназначен для печатного текста. Числа, реквизиты, таблицы и мелкий шрифт нужно сверять. Таблицы не преобразуются в таблицы Word. Изменение PDF с действующей цифровой подписью нарушает её действительность; исходный подписанный файл сохраняйте отдельно.

История ограничена по объёму памяти. Большие сканы требуют ресурсов. Сохранение использует временный файл рядом с назначением и последующую замену.

## Исходники и проверки

Лицензия программы AGPL-3.0: LICENSE.txt. Реально встроены PyMuPDF, PySide6, img2pdf и pikepdf/QPDF; условия зависимостей находятся в THIRD_PARTY.md и licenses/. Ваши подписи и печати не становятся частью лицензии программы.

SOURCES.md содержит точные ссылки на GitHub и разделяет библиотеки и самостоятельно написанные функции. BUILD_VERIFICATION.md описывает публичные проверки; подробный локальный отчёт поставляется отдельно с готовым установщиком.

Сборка: Windows 11 x64, Python 3.12, виртуальная среда, requirements.txt и build.ps1; подробности installer/BUILD.md. Для тестов установите requirements-dev.txt и запустите python -m pytest tests -q.

Самопроверка: PDFMaster.exe --self-test C:\путь\report.json. Проверяет встроенные OCR, формы, удаление области, конвертацию JPEG, оптимизацию, библиотеку штампов и выравнивание. Тестовые файлы создаются рядом с отчётом; пользовательские документы не используются.

## Автоматическая сборка и SignPath

GitHub Actions собирает исходники на GitHub-hosted Windows, запускает тесты и самопроверку, сохраняет установщик и SHA256. Проверка pull request не использует секретов подписания. Параметры запуска описаны в installer/BUILD.md и signing/eligibility.md.

Обычная сборка остаётся неподписанной. Production signing запускается вручную только из основной ветки после одобрения SignPath, настройки проекта и обязательного подтверждения выпуска. Репозиторий не содержит сертификатов, закрытых ключей или токенов. Подготовка workflow сама по себе не означает получение подписи либо отсутствие SmartScreen-предупреждений.
